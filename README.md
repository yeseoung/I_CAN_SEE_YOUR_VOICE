# 수어 인식 및 번역 모델

### 목표

장애 여부와 사용 언어에 관계없이 실시간으로 소통할 수 있는 웹 기반 수어번역 플랫폼을 개발하고자 함. 

### 배경

온라인 회의와 원격 협업이 보편화되면서 국가와 언어에 관계없이 다양한 사람들이 함께 소통하고 협업하는 환경이 확대되고 있음. 그러나 기존 화상회의 서비스는 음성 중심의 의사소통 환경을 제공하기 때문에 수어를 사용하는 청각·언어장애인이 비수어 사용자와 실시간으로 소통하는 데 어려움이 존재함. 또한 서로 다른 언어를 사용하는 사용자 간에는 언어 장벽으로 인해 원활한 의사소통이 제한될 수 있음.

### 데이터셋

- **출처**: AI Hub - 수어영상
- **사용**: 지문자 영상에 대해서만 학습 진행
